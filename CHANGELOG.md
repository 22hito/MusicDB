# Changelog

Формат — довільний хронологічний журнал за темами (не строго [Keep a Changelog](https://keepachangelog.com/), оскільки сайт деплоїться безперервно з `main`, без версійних релізів). Версії з тегами `desktop-vX.Y.Z` стосуються лише Electron-застосунку.

## 2026-09-16 — 2026-09-22

- Профілі: наповнення публічного профілю користувача (улюблені жанри, кількість прослухувань, публічні плейлисти).
- Колесо фортуни: жанр бере участь лише за наявності ≥5 пісень; переставлено легенду й панель параметрів місцями.
- Десктоп-застосунок: синхронізація гучності та вмісту нативного попап-вікна відео з головним плеєром і поточною піснею (v1.0.3 → v1.0.4).
- CI/CD: перехід деплою на Azure з OIDC/Service Principal на publish-profile (нестабільна federated-credential довіра спричиняла збої деплою).
- Прибрано надлишкові пояснювальні коментарі в коді бекенду й фронтенду.

## 2026-09-14 — 2026-09-15

- Нові підсистеми: сторінки виконавців (дискографія, підписка, сповіщення про нові пісні/текст), друзі (пошук, запити, прийняття), публічні профілі користувачів.
- Реорганізація навбару: окрема адмін-панель, випадаюче меню профілю (профіль/налаштування/друзі), позначення одного сповіщення прочитаним.
- Мобільний застосунок (React Native): брендинг, виправлення відтворення YouTube, виправлення лейауту вкладок.

## 2026-09-11 — 2026-09-13

- Публічні/приватні плейлисти, батл рояль (турнір пісень на вибування, ексклюзивне відтворення, режим наведення).
- Колесо фортуни як окрема сторінка (замість модалки), радіальні підписи, розрізнені кольори секторів.
- Десктоп-застосунок (Electron): нативне відео в окремому вікні, автооновлення через GitHub Releases, медіа-клавіші ОС.
- Реалтайм-оновлення каталогу через SignalR; оновлення дизайну навбару й мікро-інтеракцій.

## 2026-09-09 — 2026-09-10

- Початковий каталог пісень, пошук/фільтри/сортування, заявки на додавання пісень з авто-заповненням (iTunes/Last.fm/Gemini).
- Профіль (Google OAuth), улюблені пісні, історія прослуховувань, ШІ-рекомендації.
- Караоке (текст пісні), граф схожості пісень/жанрів/альбомів.
