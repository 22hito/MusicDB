# Веб-фронтенд (`wwwroot`)

Чистий HTML/CSS/JavaScript без фреймворку, збирача й npm-залежностей у продакшн-коді.

```
wwwroot/
  index.html          розмітка всіх сторінок (div#page-*) і модальних вікон
  css/                стилі — 9 шарів, порядок = каскад
  js/                 логіка — 23 модулі за функціями
  mobile-player.html  сторінка-плеєр для WebView мобільного застосунку
  popout.html         окреме вікно відео (десктоп)
  manifest.json, sw.js, robots.txt, sitemap.xml, images/
```

## JS-модулі

Звичайні `<script>` (не ES-модулі): верхньорівневі `function`/`let`/`const` спільні для всіх файлів, а функції
викликаються ще й з `onclick="…"` у розмітці. Тому **порядок у `index.html` важливий**.

| Модуль | Відповідає за |
|---|---|
| `i18n.js` | Переклади uk/en і `t()` — підключається першим |
| `navigation.js` | Випадні меню, `showPage()`, мобільний таббар і пошук, маршрутизація (History API) |
| `helpers.js` | Дрібні утиліти (`esc()` тощо) |
| `songs.js` | Таблиці пісень (каталог і ком'юніті), фільтри, улюблені, об'єднання жанрів |
| `profile.js` | Власний профіль, плейлисти; спільні модалки (`confirmModal`, `_closeModalAnimated`) |
| `recommendations.js`, `wheel.js`, `stats.js`, `top.js` | Рекомендації, колесо фортуни, картки статистики, Топ 100 |
| `forms.js` | Заявки на пісні, автозаповнення з iTunes, редагування заявки й пісні |
| `appearance.js` | Теми, колір обкладинки в інтерфейсі, налаштування (`PREFS`) |
| `auth.js` | `initApp()`, `currentUser`, шапка, дзвіночок сповіщень |
| `player.js` | Плеєр (YouTube і файли), черга, Media Session, відео-попап, караоке, біжучий рядок |
| `battle.js`, `artists.js`, `friends.js`, `graph.js` | Батл рояль, виконавці, друзі й публічні профілі, граф схожості (`<canvas>`) |
| `bug-reports.js`, `chat.js`, `ratings.js`, `nav-search.js` | Баг-репорти, спілкування, оцінки, глобальний пошук |
| `realtime.js` | SignalR: живі оновлення |
| `main.js` | Запуск застосунку — підключається **останнім** |

**Новий модуль:** створити `wwwroot/js/<назва>.js` і додати `<script src="/js/<назва>.js">` в `index.html`
перед `main.js`. Код, що виконується одразу при завантаженні (не всередині функцій), може звертатися лише до
модулів, підключених раніше.

**Лінт:** `npm run lint`. Конфіг `eslint.config.js` сам збирає верхньорівневі імена всіх модулів і передає їх
кожному файлу як глобальні, тож `no-undef` ловить справжні опечатки й між файлами.

## CSS-шари

| Файл | Вміст |
|---|---|
| `base.css` | Дизайн-система «Nocturne»: токени кольорів (oklch), теми, типографіка, навбар, сплеш |
| `components.css` | Таблиці, статистика, форми, рекомендації, колесо, батл, граф |
| `player.css` | Плеєр-бар, відео-попап, караоке |
| `layout.css` | Навігація, перемикачі, таблиця_2, сповіщення, оцінки, спілкування |
| `nocturne.css` | Фірмовий шар редизайну, «аврора», налаштування, адаптив під монітори |
| `overlays.css` | Модальні вікна, тости, баг-репорти |
| `responsive.css` | Масштаб браузера, телефон (≤768px) |
| `features.css` | Новіші функції (скріншоти, біжучий рядок, вікно підтвердження тощо) |
| `mobile-app.css` | Вигляд мобільного застосунку на телефоні: таббар, картки пісень |

Нові стилі — у відповідний шар; якщо вони мають перебивати старі, то в шар, що підключається пізніше.

## Інтерфейс

- **Маршрутизація:** кожна сторінка має власну адресу (`/top`, `/wheel`, `/chat/dm`, `/artist/{id}`, `/explore`…);
  `showPage()` ставить `data-page` на `<html>` — за ним CSS підсвічує активну вкладку.
- **Теми:** темна, сіра, світла, системна; 6 акцентних кольорів (відтінок `--ah`); налаштування інтерфейсу.
- **Телефон (≤768px):** нижній таббар, компактна шапка з розгортним пошуком, сторінка «Огляд», пісні-картки,
  плаваючий плеєр над таббаром.
- **PWA:** `sw.js` потрібен лише для встановлюваності й нічого не кешує; аудіо й картинки (редиректять на R2)
  пропускає повз себе, інакше їх блокувала б CSP-директива `connect-src`.
