# N'Owl Desktop

Десктопна оболонка (Electron) для того самого сайту MusicDB — просто
завантажує живий продакшн-сайт у власному вікні, без адресного рядка. Увесь
UI, логін, дані — той самий сайт, той самий бекенд; жодного окремого коду
фронтенду тут нема.

## Навіщо окремий застосунок, якщо це той самий сайт

Апаратні клавіші відтворення (наступна/попередня/пауза на клавіатурі чи
навушниках) неможливо надійно перехопити зі звичайної вкладки браузера —
Chromium має специфічне обмеження Media Session API саме для YouTube-based
відтворення (навіть на youtube.com next/prev не працюють без розширення
браузера). Electron дозволяє зареєструвати справжні глобальні хоткеї на рівні
ОС (`globalShortcut`) — вони спрацьовують, навіть коли застосунок згорнутий і
у фокусі, наприклад, гра.

## Запуск (розробка)

```bash
npm install
npm start
```

## Збірка встановника (.exe)

```bash
npm install
npm run build
```

Результат — інсталятор (NSIS) і portable-версія в `dist/`.

## Що не варто тут чіпати

- Немає окремого фронтенд-коду — весь UI живе в `wwwroot/index.html`
  основного репозиторію й деплоїться на Azure як завжди.
- `main.js` лише завантажує `SITE_URL` і прокидає глобальні медіа-хоткеї в
  сторінку через `executeJavaScript` — якщо на сайті зміниться назва функцій
  плеєра (`playerNext`/`playerPrev`/`playerToggle`/`playerClose`), треба
  оновити виклики тут теж.
