# Legacy SQL-скрипти

Історія змін схеми до переходу на EF Core Migrations (до 24.09.2026). Скрипти вже застосовані
до всіх баз і **не запускаються** — лише для довідки. Їхній сумарний результат зафіксовано
в базовій міграції `Data/Migrations/*_Baseline.cs` (точна схема продакшну).

Нові зміни схеми — лише через EF Core Migrations (див. `docs/database.md`).
